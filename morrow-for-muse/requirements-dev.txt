# install stays stdlib-only (+ the optional hash-pinned cryptography).
#
#   requests: the Moodle lane (moodle/session.py, moodle/login.py,
#     moodle/probe.py, moodle/reauth.py) and the lane detector
#     (lanes/detect.py). Pinned 2.34.2 (latest on PyPI 2026-09-21).
#   opencv-python-headless: qr-proof/qr_proof.py only (`cv2.imread`
#     + QRCodeDetector on educator-supplied screenshots). Kept as the
#     executable record of the QR-bootstrapped mobile OAuth proof.
#     Pinned 5.0.0.93. Untrusted image codec risk: imread parses
#     attacker-influenced image bytes; the native codecs have a long
#     CVE history, so the pin stays on an audited build.
#
# Hash-locked (W4-P2-24/W4-P2-25): --require-hashes means pip verifies
# every downloaded artifact against one of the hashes below before
# installing. The FULL transitive closure is pinned, because with
# --require-hashes pip refuses to install ANY package that lacks a
# listed hash, including transitive dependencies:
#   - requests==2.34.2 requires charset-normalizer, idna, urllib3, certifi
#   - opencv-python-headless==5.0.0.93 requires numpy (>=2 on Python 3.9+)
#   - numpy==2.2.6 is the latest numpy supporting the Python 3.11 floor
#     (numpy 2.5.x requires Python >=3.12); it has no dependencies.
#   - charset-normalizer, idna, urllib3, certifi have no runtime deps
#     (idna/urllib3 extras are not used).
#
# Coverage (2026-09-21): wheels for CPython 3.11 and 3.12 on manylinux
# x86_64 (the reference dev VM), plus sdists for the pure-Python
# packages (requests, idna, urllib3, certifi) and charset-normalizer
# as the fallback. Binary sdists for numpy and opencv-python-headless
# are not hashed here; other platforms regenerate via the recipe below.
# Regenerating hashes when a pin is raised: download the new
# version's artifacts into the scratch lock dir and re-run
# gen-dev-lock.py, e.g.
#   pip download --no-deps -d <lockdir> "requests==X.Y.Z"
#   pip download --no-deps --no-binary :all: -d <lockdir> "requests==X.Y.Z"
# (repeat for each package in the closure; for binary wheels add
# --platform/--python-version/--abi as needed). Then re-run the
# offline-install proof below.
#
# Offline-install proof (2026-09-21): a fresh venv installed with
# --no-index --find-links on the local artifact dir, WITH dependencies
# (not --no-deps), so the transitive closure is exercised.
