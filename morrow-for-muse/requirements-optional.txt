# Optional dependencies for Morrow for Muse (exact pins, tested 2026-09-24).
#
# Canvas course-content work by student name needs cryptography. The
# Moodle session lane needs requests. Install this file before using
# either feature. install.sh and every selftest pass without these
# packages.
#
#   requests: Moodle's session-authenticated API and form lane. The
#     cookie jar and sesskey stay in memory; nothing writes their values.
#     Latest stable release on PyPI when packaged: 2.34.2.
#
#   cryptography: the encrypted learner vault (privacy/core.py). Without
#   it, Morrow refuses everything that touches student data (finding a
#   student by name, the failed-students question, rosters, grades,
#   submissions) with a message telling the educator to install this
#   file. Student names in course content are hidden without labels,
#   and a change that would save one back is refused. Everything else
#   works.
#
# Hash-pinned (W4-P2-19): --require-hashes means pip verifies every
# downloaded artifact against one of the hashes below before
# installing. A compromised mirror or MITM cannot substitute a
# tampered wheel for the package that guards the encrypted learner
# vault. The pin floor is >= 50.0.1 (W4-P2-20): older releases carry
# CVE-2026-69247, CVE-2026-69248, and CVE-2026-69249.
#
# Full closure, not just the direct pin: with --require-hashes pip
# refuses to install ANY package that lacks a listed hash, including
# transitive dependencies. So the closure is pinned too:
#   - cryptography==50.0.1 (requires cffi on CPython)
#   - cffi==2.1.1 (requires pycparser on CPython)
#   - pycparser==3.0 (pure Python, no deps)
#
# Coverage per package:
#   - cryptography: the sdist plus every wheel 50.0.1 ships on PyPI
#     (manylinux2014 x86_64/aarch64, musllinux x86_64/aarch64,
#     macosx_11_0 arm64, win_amd64; cp311-abi3 covers Python 3.11+).
#   - cffi: wheels for cp311/cp312/cp313/cp314 on manylinux2014
#     x86_64, macosx_11_0 arm64, win_amd64 (plus cp312
#     manylinux2014 aarch64), plus the sdist as the fallback for
#     every other platform (musl, Intel macOS, win32, other
#     interpreters: cffi builds from C, no Rust needed).
#   - pycparser: the universal py3 wheel plus the sdist.
# Regenerating hashes when the pin is raised: download the new
# version's artifacts and run `pip hash` on each, e.g.
#   pip download --no-deps --only-binary :all: \
#       --platform manylinux2014_x86_64 -d /path/to/dl "cryptography==X.Y.Z"
#   pip hash /path/to/dl/*
# (repeat --platform for each platform above; the sdist needs no
# build: `pip hash` reads the file directly). Replace the version and
# every --hash line below, then re-run the carve smoke so the dist is
# validated against the new pin (W4-P2-21).
