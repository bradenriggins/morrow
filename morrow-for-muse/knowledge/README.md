only the topic needed for the task. Read another topic when the task crosses
its boundary. Do not load every document before every call.

The current executor, admission policy, and dispatch catalog determine whether
an operation can run. Design advice and platform documentation do not override
them. Historical proof dates are evidence dates, not a promise of current
permission or current site availability. When a runtime claim conflicts, read
the enforcing source and fix the claim; never bypass the control.
