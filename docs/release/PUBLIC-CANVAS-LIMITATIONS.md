# Public Canvas candidate limitations

This local candidate contains the standalone Morrow MCP, the directly owned Chrome connector, and the Canvas-only generated catalog. It contains no required legacy Morrow or ExamplePlatform runtime.

It is not published software. Candidate creation does not authorize a provider change, a stable tag, a package-registry release, a Chrome Web Store release, or a public Instructure compatibility claim.

Promotion requires current receipts for:

- per-file source rights;
- intended Canvas authorization basis;
- authorized live Canvas operation and readback;
- real-client parity;
- independent clean-machine reproduction;
- public package scan, checksums, and SBOM;
- explicit publication authorization.

The runtime uses only the current signed-in user's Canvas permissions. It cannot bypass institutional policy, browser controls, role permissions, New Quizzes access, or Item Bank access.

MindTap, Connect, private institutional material, private paths, credentials, learner identity fixtures, and historical donor runtimes are excluded from the public profile.
