# What Counts as a Finished AI-Assisted Course Change?

**Status:** Draft for author review.

A draft prepared with AI assistance can start course work. A course team still needs to see the exact course and proposed edit, approve that edit, and check the saved learner experience.

A finished course change has evidence for six facts: the source, the exact course item, the proposed change, the educator's approval, what the LMS saved, and the learner path. A generated paragraph, provider response, or green log cannot establish all six.

## Confirm the course and item before making a change

Before Morrow offers a review, it identifies the current account, course, platform, and course item. It checks that the item still matches the content used to prepare the proposal. If the course, page, tab, or target has changed, the team starts a fresh review.

For Canvas pages, the check includes the URL, title, body, publication state, front-page state, editing roles, update time, and revision fields. This lets a team confirm more than a changed sentence. [Canvas Pages API](https://canvas.instructure.com/doc/api/pages.html)

## Make the change readable

A reviewer should see the current wording, proposed wording, course item, and conditions that stay the same. “Fix the biology page” needs interpretation. “Replace this sentence while preserving these fields” gives the educator a decision they can make.

In a bounded Canvas test, the supplied source stated that ribosomes are responsible for protein synthesis. The saved lesson assigned ATP production to ribosomes. The source distinguishes ribosomes from mitochondria on this point. [OpenStax Biology 2e, 4.3 Eukaryotic Cells](https://openstax.org/books/biology-2e/pages/4-3-eukaryotic-cells)

Two independent review requests found that lesson conflict and a related wrong saved quiz answer key. A separate checker retained both findings. The exchange used a manual adapter, so it is evidence for that limited review route. It does not establish automatic sampling behavior in every assistant.

Before anything is sent, the review shows the old text, replacement, and conditions that stay the same. An assistant can propose the change. An educator decides its source, scope, and learning consequence.

## Approve one reviewed change

Approval applies to one reviewed change for one named course item. It does not give an assistant permission to make later changes.

A controlled batch shows every target before approval, keeps a result for each one, and stops starting new work after uncertainty.

## Check what the LMS saved

After approval, the saved LMS record is the evidence that matters.

In the Canvas test, a new Canvas check confirmed one intended lesson phrase change. The page title, URL, publication state, front-page state, and editing roles stayed unchanged.

The related New Quiz correction also reached a confirmed saved result. The comparison showed that only question one's saved scoring value and update time changed; the other question fields stayed unchanged. Two module-link writes and three publication operations also reached confirmed saved results.

This supports selected saved changes in one sandbox sequence. It does not prove every Canvas operation, content type, or instructional decision.

A later proposal relied on outdated page content. It stopped before sending a change, and a later Canvas check showed the same body and update time. If the result of a change is uncertain, inspect the named course item before deciding what to do next. Do not automatically repeat a change that might have already happened.

## Keep the privacy boundary visible

For Canvas and Moodle, sign-in stays in Chrome. Credentials stay out of assistant messages and saved records. Morrow blocks credential and learner fields from assistant output. The selected course text and metadata needed for the request can still reach the chosen assistant under that assistant's own account settings and data terms.

This is a specific boundary, not a claim that all course data stays local. A course team should decide whether its chosen assistant is appropriate for the selected content.

## Keep provider scope specific

The review-and-check model can travel across LMS providers. The proof cannot.

Canvas has selected live sandbox evidence through a signed-in Chrome connection. Moodle uses the same connection. In a test course, Morrow completed course and structure reads; created hidden Pages, Assignments, and Quizzes without questions; edited a Page, Assignment instructions, and Quiz instructions; and set or cleared Assignment due dates and Quiz open/close dates. Selected test-course work also covered Page and section visibility and reading Multiple choice and Essay questions. Each result was saved and checked. Question authoring, random and other question types, file uploads, and file edits are not available yet. Other activity types, section cases, and broader settings still need checks. Blackboard browser connection is not yet verified, so Blackboard course work is unavailable.

Morrow is working toward the same core features across all three platforms. It does not claim current parity. Blackboard course work remains unavailable until its browser connection is verified. Provider-specific scope prevents one provider's evidence from becoming another provider's claim.

## Finish at the learner path

The final question is about the learner. Can the learner find the lesson, complete the assessment, and receive the intended experience?

In the selected Canvas sandbox route, Student View showed the published lesson with the corrected text. Next Module Item launched the quiz, and Begin showed all three questions. After the correct choices were submitted, the assessment result showed 100%, three of three points, the correct ribosomes answer, and all three feedback messages.

That establishes one learner route through one published sandbox sequence. It does not establish every learner flow, learning effectiveness, a full Canvas catalog, or release readiness.

That is the standard worth keeping: show the exact target and proposed change, approve one change, check the saved result, and inspect the learner path when it matters. AI assistance can help prepare the work. A course change is finished only when the record supports what the team says happened.
