## Morrow evidence to use

Use this bounded description:

> Morrow is a course-operations layer for AI-assisted LMS work. It binds a
> request to an account, course, and target; shows a readable review; requires
> approval; and reads the LMS again to distinguish verified, unconfirmed, and
> failed results. Its 180 tests passed. In live Canvas work, lesson and quiz-key
> corrections were verified, independent readback confirmed all other quiz fields
> were unchanged, a stale request was refused before send, and module links were
> verified. The selected Student View path passed, and Canvas Grades plus an
> independent API read confirmed the 3/3 test result. Moodle and Blackboard have
> API and adapter validation only, not live-tenant proof.

Do not claim general availability, live Moodle or Blackboard proof, or broad learner-population results. The [hiring case study](05-HIRING-CASE-STUDY.md) has
the full evidence boundary.
