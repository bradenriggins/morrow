## Morrow evidence to use

Use this scope-limited description:

> Morrow helps course teams turn an assistant request into a reviewed course change and a checked LMS result. It shows the exact course, current content, and proposed edit before an educator approves one change. It then checks the LMS again and reports verified, unconfirmed, or failed results. An uncertain result stays visible for attention and does not repeat automatically. Its relevant test gates passed. In selected live Canvas sandbox work, lesson and quiz-key corrections were verified, independent checks confirmed all other quiz fields were unchanged, a request based on an older page version was refused before send, and module links were verified. The selected Student View path passed, and the gradebook matched the 3/3 test result. Moodle uses the same Chrome connection as Canvas. Its selected test-course proof covers course reads; Page, Assignment, and Quiz creation without questions; editing Pages, Assignment instructions, and Quiz instructions; and setting or clearing Assignment due dates and Quiz open/close dates. Selected test-course work also covered Page and section visibility and reading Multiple choice and Essay questions. Question authoring, random and other question types, file uploads, and file edits are not available yet. Other activity types, section cases, and broader settings still need checks. Blackboard browser connection is not yet verified and Blackboard course work is unavailable.

Do not claim general availability, proof for every Moodle write, Blackboard browser availability, blanket platform parity, or broad learner-population results. The [hiring case study](05-HIRING-CASE-STUDY.md) has the full evidence boundary.
