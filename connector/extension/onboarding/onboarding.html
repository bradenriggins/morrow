Morrow setup

Use Morrow to connect an assistant and a permitted course. You can close this guide and return at any time.

Checking setup

Morrow is checking this connection.

  • Assistant approval is not checked
  • Morrow Bridge connection is not checked
  • Morrow version is not checked
  • Course connection is not checked
  • First read is not checked

Open Morrow

Open Morrow, choose your assistant, then return to Morrow Bridge.

Open the Morrow app and choose your assistant. Then return to Morrow Bridge and select Connect Morrow.

All setup steps

  1. Open Morrow

    Open the Morrow app and choose your assistant.

    Chrome works with one Morrow at a time. A second Morrow reports that another Morrow is already using this connection, and it starts without its course tools. Close the other Morrow, or use one Morrow for all your assistants.

  2. Connect Morrow Bridge

    Return to Morrow Bridge and select Connect Morrow. In the Morrow page that opens, select Allow connection only if you started it.

  3. Connect a course site

    Open a permitted Canvas or Moodle course in Chrome and sign in. In Morrow Bridge, select Connect course site, then allow Chrome access to that exact course site.

  4. Select a course in Plan

    Open Plan and Edit settings. Select Find available courses, choose a course, then select Connect selected courses in Plan.

  5. Try a first read

    Return to your assistant and ask: Use Morrow to list the modules in my selected course.

Plan keeps changes in review

Connecting a course selects it in Plan. A change in Plan waits for your review. You choose if and when to grant Edit access later in Plan and Edit settings.
