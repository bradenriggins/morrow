# Appendix C path map

This map ratifies the current gateway architecture against Appendix C of the
Weekend Example Plan. The plan named target paths before the workspace
converged. The implementation uses the paths in
`config/appendix-c-path-map.json` instead.

The map is a release gate. Every planned path has one explicit disposition.
`owned-by-donor` and `not-implemented` entries remain candidate blockers when
their planned behavior is required by the selected profile. The map does not
grant source rights, provider authority, or live-proof status.
