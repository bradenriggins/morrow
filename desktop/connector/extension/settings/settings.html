What this permission allows

Chrome grants this permission across HTTPS sites because Canvas can store course files on different domains. During one reviewed upload, Morrow observes only that Canvas-issued upload response until it gets a Canvas confirmation. It does not block or change requests. Morrow reads or transfers only files it confirms belong to selected Canvas courses. The same permission covers the image bytes for a Hot Spot question you approved, sent once to the upload address Canvas's own response names for that upload.

How Plan and Edit access work
  • Plan keeps changes ready for your review.
  • Edit applies only to the selected courses and checked actions.
  • Return a course to Plan to remove saved Edit access immediately.
  • Edit access stays on until you return the course to Plan. This includes Edit access you allow in a Morrow conversation.
  • Some actions cannot be checked after they are saved. Morrow marks them here and reports the saved result as unconfirmed.
  • If a course needs sign-in again, select Open Canvas or Open Moodle on its row, and sign in if asked.
